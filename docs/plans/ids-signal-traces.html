Trace figures drawn from IDS

IDS Signal Traces

imas-ink draws only from IDS inputs, or from signals carrying standard-name metadata (lead ruling, 2026-10-07). Its geometry path already works this way: extract_geometry reads the wall, pf_active and magnetics IDS. Its only trace extractor, extract_time_traces, reads equilibrium global quantities. Nothing reads a pulse's measured signals, so imas-ambix's JT-60SA signal figures handed TimeSeries bare arrays. They took values from a signal-map view, plotted raw EDDB channels, and labelled them with strings the caller chose. This plan gives imas-ink the missing reader, so a caller hands over the IDS and imas-ink names the signal and its unit itself.

§1 — Read a dynamic signal's traces from its IDS

Landed extract_signal_traces(ids, path), exported from imas_ink (merge 036d8fb). It returns one TimeSeries per filled element along an unindexed data-dictionary path, reading values, time base (homogeneous time 1 or 0), unit and name from the IDS. It refuses an indexed path and homogeneous time 2. Six in-memory tests were added: the unit suite went from 419 to 425 passed, with no failures. Review scored 120/120. full record
