Annular vessel skins in the 2D geometry figure

The vessel types and extractor moved into core modules so the 2D figure no longer loads the 3D subpackage: WallOutline2D and VesselShell now live in imas_ink/_types.py, extract_vessel_shells in imas_ink/extract.py, and the pure-numpy _offset_polygon in imas_ink/geometry.py. three_d/walls.py imports all three from their new homes and its private _safe_float (its only caller was the moved extractor) is deleted. The lazy name map in imas_ink/__init__.py points VesselShell/WallOutline2D at _types.py and extract_vessel_shells at extract.py.

extract_vessel_shells(wall_ids, desc_2d=None) takes the description_2d entry to read (index 0 when none is given) and, when an annular unit's outline_inner and outline_outer are filled, returns one closed VesselShell for each — inner then outer — ahead of the unchanged centreline and outline paths. It reads thickness through imas_ink._sentinel.safe_float. extract_geometry passes the entry _select_description_2d chose and fills MachineGeometry.vessel_shells, whose viewport now includes the shells' bounds.

WallOutline carries the shells; _render_wall_mpl and _render_wall_alt draw them as unfilled lines in wall_color/wall_linewidth, the altair renderer gaining the wall_units loop the matplotlib renderer already had. geometry_figure_mpl and equilibrium_chart_alt pass the shells to the WallOutline they already build.
