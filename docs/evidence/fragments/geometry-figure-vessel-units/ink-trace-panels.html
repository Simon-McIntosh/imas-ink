Several traces on one panel

time_trace_figure_mpl (imas_ink/figures.py) accepts each panel as one TimeSeries or a list of them. The first series is drawn exactly as a single series is today and owns the panel's labels and colour; each later series is drawn by calling _render_timeseries_mpl (imas_ink/mpl.py) directly with color set to the first line's colour and label_axes=False, so it adds a line in its own trace_linestyle and writes no y-label, x-label or legend. The public render_mpl signature is unchanged. InkStyle (imas_ink/style.py) gains trace_linestyle (default "solid"), applied by _render_timeseries_mpl and _render_timeseries_alt (imas_ink/alt.py); the altair stroke-dash map now accepts matplotlib's shorthand forms ('-', '--', ':', '-.') as well as the named ones, so both renderers draw the same style for each.
