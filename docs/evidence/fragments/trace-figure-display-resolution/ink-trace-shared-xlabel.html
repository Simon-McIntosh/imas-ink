Label a stacked figure's shared x-axis once

_render_timeseries_mpl and _render_radialprofile_mpl (imas_ink/mpl.py) each gain a private keyword label_x (default True) that alone controls whether the axes' x-label (Time [s] / ψ_norm) is written; the exported render_mpl gains no keyword. time_trace_figure_mpl and radial_profile_figure_mpl (imas_ink/figures.py) now call the private renderers directly and pass label_x=False for every panel but the bottom one, so a stacked figure labels its shared axis once. Measure tests/unit/test_trace_resolution.py — three tests, all passing: a three-panel trace figure and a three-panel radial-profile figure each carry a non-empty x-label on the bottom axes only, and a lone TimeSeries drawn through render_mpl still carries Time [s].
