Read a signal's traces from its IDS

imas_ink/extract.py gains extract_signal_traces(ids, path), exported from imas_ink: one TimeSeries per filled element of every struct array an unindexed, IDS-relative data-dictionary path passes through, reading values, unit and y-label from the IDS alone. Six tests in tests/unit/ink/test_signal_traces.py (pf_active coils, magnetics ip, homogeneous-time-0 flux loops, the time-base and indexed-path refusals, no label) pass.
