§1 — a pulse's signals read as traces from its IDS

imas_ink/extract.py gained extract_signal_traces(ids, path), exported beside extract_time_traces. It walks an unindexed data-dictionary path, expanding every struct array on the way, and returns one TimeSeries per element whose data is filled. Each series takes its time from ids.time under homogeneous time 1 and from the node's own time under 0. Its unit comes from node.data.metadata.units, and its y-label from the element's non-empty name, falling back to the path's leading component. No series carries a legend label. A path holding an index, and homogeneous time 2, raise ValueError. Nothing is scaled, filtered or resampled.

tests/unit/ink/test_signal_traces.py builds IDS in memory with imas.IDSFactory. It covers a three-coil pf_active with one unfed coil, which yields two series in A; a magnetics ip; flux loops under homogeneous time 0, each with its own flux.time in Wb; and both refusals.

tests/unit gave 425 passed against 419 at base df18016, with no failures, and ruff reported no findings at either revision. Negative control: reading ids.time regardless of homogeneous_time fails only the homogeneous-time-0 test. The review scored all six items 20.

One nit stays open. _is_struct_array imports IDSStructArray through the re-export in imas.ids_structure rather than its defining module, imas.ids_struct_array. That is the same class in imas-python 2.2, and a failed import would raise on the first struct array rather than return wrong traces.

§1 follow-up — struct-array import nit closed

The nit recorded at landing is fixed in commit 67a0ce3. _is_struct_array now imports IDSStructArray from its defining module, imas.ids_struct_array, instead of the re-export in imas.ids_structure. It also drops the except Exception fallback that treated every node as a scalar struct when the import failed. imas-python is a core dependency of imas-ink, so that fallback could only hide a broken install. The import stays inside the function, matching the package's lazy imas imports.

A separate commit, f9b9259, applies ruff format to the reader's two split error strings under the repository's current line length; behaviour is unchanged. tests/unit/ink/test_signal_traces.py and test_extract.py pass: 42 tests after the fix, 6 after the format commit. Ruff check is clean.
